## 下層ページメモ

### 提供サービス `/service/`

- 目的: 訪問看護で対応できる内容を分かりやすく伝える
- 主な内容:
  - ページタイトル
  - 対応サービス
  - 利用対象者
  - 利用開始までの流れ
  - お問い合わせ導線

### お知らせ `/news/`

- 目的: 事業所からの更新情報を掲載する
- 主な内容:
  - お知らせ一覧
  - 個別記事の有無確認
  - 更新方法の確認

### 災害・感染症対策 `/case-study/`

- 目的: 災害時・感染症流行時の対応方針を伝える
- 主な内容:
  - ページタイトル
  - 対策内容
  - 利用者・家族への案内

### 会社概要 `/company/`

- 目的: 事業所情報と運営元を伝える
- 主な内容:
  - 事業所名
  - 所在地
  - 電話番号
  - 対応エリア
  - 運営会社情報

### お問い合わせ `/contact/`

- 目的: 利用相談や問い合わせにつなげる
- 主な内容:
  - 電話導線
  - フォーム
  - 個人情報の扱い
  - 送信完了導線

### プライバシーポリシー `/privacy/`

- 目的: 個人情報の取り扱いを明示する
- 主な内容:
  - 個人情報保護方針
  - 問い合わせ先

### 利用規約 `/terms/`

- 目的: 必要な場合のみ規約ページとして使用する
- メモ: 訪問看護サイトで必要か要確認
